DOKUMENTASI STRUKTUR MODEL VRM
Karakter: Kohaku (狐薄)
Sumber Analisis: Struktur folder hasil import Unity (ls -R)

---

1. INFORMASI UMUM MODEL

Model karakter yang dianalisis adalah model 3D format VRM yang telah diimport ke dalam Unity. Berdasarkan struktur folder yang ditemukan di direktori Assets, model ini memiliki komponen lengkap yang terdiri dari:

* Avatar definition
* BlendShape system
* Mesh objects
* Materials
* Textures
* Scene file

File utama model:

Kohaku_dress_1.10_VRM.vrm
Kohaku_dress_1.10_VRM.prefab

File tersebut menunjukkan bahwa model sudah siap digunakan dalam Unity dan VRM runtime.

---

2. SISTEM AVATAR DAN HUMANOID RIG

Folder yang ditemukan:

Kohaku_dress_1.10_VRM.Avatar
Kohaku_dress_1.10_VRM.AvatarDescription

File:

VrmAvatar.asset
AvatarDescription.asset

Keberadaan file ini menunjukkan bahwa model menggunakan sistem:

Humanoid Avatar Rig

Humanoid rig adalah struktur bone standar Unity yang memungkinkan karakter untuk:

* menggunakan sistem animasi humanoid
* kompatibel dengan animator Unity
* kompatibel dengan VRM runtime
* mendukung retarget animation
* mendukung full body tracking

Artinya model ini memiliki struktur tulang seperti:

Hips
Spine
Chest
Neck
Head
Shoulder
Arm
Forearm
Hand
Leg
Foot

Struktur ini merupakan standar rig humanoid yang digunakan oleh Unity dan VRM.

Dengan adanya blendshape ini, karakter mampu melakukan:

* animasi wajah
