### Penjelasan Gambar:
1. **Paling Atas (User):** User menggunakan suara dan melihat ke layar handphone.
2. **Layer Tengah (Android):** Ini adalah *rumah* sebenarnya dari aplikasi ini. Semua mikir, rekam suara, internet nembak OpenClaw, nembak ElevenLabs, itu dikerjain di kotak ini. Kotak ini me-*manage* baterai dan proses kerja secara *background* maupun sebagai layanan mengambang (Floating Service).
3. **Layer Bawah (Unity):** Unity dipenjara/dibungkus dan dimasukkan ke dalam Android (sebelah kanan atas: *UaaL Bridge* dan *Floating Service*). Unity tidak mengakses internet, tidak merekam suara secara native. Unity cuma duduk diam nunggu disuruh Android: *"Hei Unity, mainkan audio ini dan pasang muka ceria!"*.
   - Begitu data masuk ke `JNI Bridge` di Unity, barulah script `C# System`-mu (seperti GestureSystem.cs, LipSyncSystem.cs) menyala.
   - Script ini menyuruh `Animator` untuk mengganti *pose* dan mengubah ukuran `Blendshape` pada **Kohaku VRM Model** kamu.

File teks kotak ini sudah aku simpan biar kamu bisa buka juga kapan saja.
